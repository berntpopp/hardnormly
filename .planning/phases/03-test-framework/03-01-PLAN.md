**Step 2: Create `tests/test_helper/common.bash`.**

This shared helper is sourced by every test file. It provides:

1. `_common_setup()` — loads bats-support, bats-assert, bats-file; computes REPO_ROOT from BATS_TEST_FILENAME; exports canonical paths (HARDNORMLY, TEST_DATA, SYNTH, REAL_DATA, EXPECTED, TEST_TMP).

2. `_require_tools()` — checks for bcftools, bedtools, bgzip, tabix; calls `skip "Required tools not found: ..."` if any are missing. This allows smoke tests to run without bioinformatics tools.

3. `_get_filter()` — extracts the FILTER field for a specific position from a VCF using `bcftools query -r "22:${pos}-${pos}" -f '%FILTER\n'`. Takes two args: vcf path and position. Returns the FILTER string.

```bash
# tests/test_helper/common.bash

_common_setup() {
    load 'test_helper/bats-support/load'
    load 'test_helper/bats-assert/load'
    load 'test_helper/bats-file/load'

    # Compute repo root from test file location
    REPO_ROOT="$(cd "$(dirname "$BATS_TEST_FILENAME")/.." >/dev/null 2>&1 && pwd)"
    export REPO_ROOT

    # Canonical paths to key assets
    HARDNORMLY="${REPO_ROOT}/hardnormly.sh"
    TEST_DATA="${REPO_ROOT}/tests/data"
    SYNTH="${TEST_DATA}/synthetic"
    REAL_DATA="${TEST_DATA}/real"
    EXPECTED="${TEST_DATA}/expected"
    export HARDNORMLY TEST_DATA SYNTH REAL_DATA EXPECTED

    # Per-test temp directory provided by BATS
    TEST_TMP="${BATS_TEST_TMPDIR}"
    export TEST_TMP
}

# Skip test if bioinformatics tools are not available
_require_tools() {
    local missing=()
    for tool in bcftools bedtools bgzip tabix; do
        command -v "$tool" >/dev/null 2>&1 || missing+=("$tool")
    done
    if [[ ${#missing[@]} -gt 0 ]]; then
        skip "Required tools not found: ${missing[*]}"
    fi
}

# Extract FILTER field for a specific chromosome position from a VCF
# Usage: _get_filter <vcf> <chrom> <pos>
# For chr22 VCFs: _get_filter "$vcf" 22 10200
_get_filter() {
    local vcf="$1"
    local chrom="$2"
    local pos="$3"
    bcftools query -r "${chrom}:${pos}-${pos}" -f '%FILTER\n' "$vcf"
}
```

**IMPORTANT design note on `_get_filter`:** The helper takes 3 args (vcf, chrom, pos) rather than 2 to support both synthetic VCFs (chrom=22) and real data VCFs that may use different chromosome naming. This is forward-compatible with hg38 tests using "chr22".

**Step 3: Write `tests/01-smoke.bats`.**

Smoke tests verify CLI argument handling without bioinformatics tools. NO `_require_tools` call in setup.

**CRITICAL:** `hardnormly.sh` `show_help()` exits with code 1 (not 0). The `--help` flag calls `show_help` which does `exit 1`. So `--help` test must use `assert_failure` (not `assert_success`). The `--version` flag exits 0.

Tests to include:
1. `--help exits with non-zero and shows usage` — run --help, assert_failure, assert_output --partial "Usage:"
2. `--version exits 0 and prints version` — run --version, assert_success, assert_output --partial "Version:"
3. `missing -v flag exits non-zero` — run with -f /dev/null only, assert_failure
4. `missing -f flag exits non-zero` — run with -v /dev/null only, assert_failure
5. `no arguments exits non-zero` — run with no args, assert_failure
6. `unknown parameter exits non-zero` — run with --bogus-flag, assert_failure, assert_output --partial "Unknown parameter"

```bash
#!/usr/bin/env bats
# tests/01-smoke.bats — CLI argument validation (TFWK-01)
# These tests run WITHOUT bioinformatics tools (no _require_tools call)

setup() {
    load 'test_helper/common'
    _common_setup
}

@test "--help shows usage and exits non-zero" {
    run "$HARDNORMLY" --help
    assert_failure
    assert_output --partial "Usage:"
}

@test "--version prints version string and exits 0" {
    run "$HARDNORMLY" --version
    assert_success
    assert_output --partial "Version:"
}

@test "no arguments exits non-zero" {
    run "$HARDNORMLY"
    assert_failure
}

@test "missing -v flag exits non-zero" {
    run "$HARDNORMLY" -f /dev/null
    assert_failure
}

@test "missing -f flag exits non-zero" {
    run "$HARDNORMLY" -v /dev/null
    assert_failure
}

@test "unknown parameter exits non-zero" {
    run "$HARDNORMLY" --bogus-flag
    assert_failure
    assert_output --partial "Unknown parameter"
}
```

Replace the existing placeholder `test` job with a real BATS job. Use the submodule approach (not bats-action) for simplicity.

The updated test job must:
- Checkout with `submodules: recursive` to get BATS libraries
- Install bcftools and bedtools via apt-get (for filter and integration tests)
- Run all BATS tests with `--print-output-on-failure` for diagnostic output on failures

```yaml
  test:
    name: Test
    runs-on: ubuntu-latest
    steps:
      - name: Checkout
        uses: actions/checkout@v4
        with:
          submodules: recursive

      - name: Install bioinformatics tools
        run: sudo apt-get update && sudo apt-get install -y bcftools bedtools
```
