**IMPORTANT: Use `$HARDNORMLY` directly (not `run "$HARDNORMLY"`) in setup_file().**
When using `run` in setup_file(), the return value check uses BATS assertion context which may not work correctly. Instead, call the script directly. If it fails, setup_file() will fail and all tests in the file will be skipped.

**Per-test assertion pattern:**

For each filter, write TWO types of tests:
1. **Positive assertion:** A variant designed to FAIL the filter IS tagged.
2. **Negative assertion:** A control variant that should PASS is NOT tagged.

Use `_get_filter` from common.bash:
```bash
@test "DPu10het: low DP het variant is tagged" {
    local actual
    actual=$(_get_filter "$OUTPUT_VCF" 22 <POS_FROM_INSPECTION>)
    assert_equal "DPu10het" "$actual"
}

@test "DPu10het: adequate DP het variant is not tagged" {
    local actual
    actual=$(_get_filter "$OUTPUT_VCF" 22 <CONTROL_POS>)
    # Verify no DPu10het tag (could be PASS, ., or another filter name)
    refute [ "$actual" = "DPu10het" ]
}
```

**Multi-filter test:** At least one variant should trigger multiple filters simultaneously. Verify the combined FILTER field:
```bash
@test "multi-filter: variant triggers DPu10het and gatkSNPhard" {
    local actual
    actual=$(_get_filter "$OUTPUT_VCF" 22 <MULTI_FILTER_POS>)
    # Combined tags in filter-file order, semicolon-separated
    assert_equal "DPu10het;gatkSNPhard" "$actual"
}
```

**IMPORTANT: Replace ALL `<POS_FROM_INSPECTION>` placeholders with actual position numbers discovered in the first step.** Do NOT submit a test file with placeholder values. Every position must be a real integer from the synthetic VCF.

**Minimum test count:** At least 1 positive + 1 negative assertion per filter (7 filters = minimum 14 tests). Plus at least 1 multi-filter combined tag test. Total: minimum 15 `@test` blocks.

**Edge case to watch:** The INCLUDE_REGION/EXCLUDE_REGION annotation step may affect which variants appear in the output. Some synthetic variants might fall outside the include region. Check the include_regions.bed range and verify all test positions are within it.
