  <action>
Create `lib/logging.sh` with the following structure:

1. **Include guard** at top:
   ```bash
   [[ -n "${_LIB_LOGGING_LOADED:-}" ]] && return 0
   readonly _LIB_LOGGING_LOADED=1
   ```

2. **Global state variables** (the justified exception — logging config):
   ```bash
   _LOG_FILE=""
   _DEBUG=false
   _TMP_DIR=""
   ```

3. **Setter functions** (called by hardnormly.sh after arg parsing):
   - `set_log_file()` — sets `_LOG_FILE`
   - `set_debug()` — sets `_DEBUG`
   - `set_tmp_dir()` — sets `_TMP_DIR`

4. **log_msg()** — identical behavior to current hardnormly.sh lines 84-92. Uses `_LOG_FILE` global. Format: `[$timestamp] $message`. Writes to `_LOG_FILE` if set, otherwise stdout.

5. **debug_msg()** — identical to current lines 95-99. Checks `_DEBUG` global. Calls `log_msg "[DEBUG] $1"`.

6. **error_msg()** — new function (not in current script). Writes to stderr: `log_msg "ERROR: $1" >&2`.

7. **run_cmd()** — the core error handling wrapper (replaces ERR trap for external commands):
   - Creates stderr temp file in `_TMP_DIR` if set, otherwise `/tmp` (fallback for early calls before tmp_dir exists)
   - Runs command via `"$@" 2>"$stderr_file"`
   - On failure (exit != 0): calls `error_msg` with command name, exit code, full command, and stderr content. Removes temp file. Returns the exit code.
   - On success: removes temp file, returns 0.
   - Pattern from research: `stderr_file=$(mktemp "${_TMP_DIR:+${_TMP_DIR}/}runcmd-XXXXXX")` — uses `_TMP_DIR` if set, otherwise mktemp default.

8. **run_cmd_with_retry()** — retry wrapper for network operations only (UCSC MySQL):
   - Takes `max_attempts` as first arg, then passes remaining args to `run_cmd`
   - Loops up to `max_attempts`, sleeping 2s between attempts
   - Logs each retry attempt via `log_msg`
   - On all attempts failed: calls `error_msg`, returns 1

Ensure shfmt compliance (`-i 0 -bn -ci`): use tabs, binary ops at start of line, `|| {` on multi-line blocks. Ensure shellcheck compliance (no warnings).

Important: The `debug_msg` function must use `[[ "$_DEBUG" == "true" ]] || return 0` pattern (not `$debug` boolean test) since `_DEBUG` is a string, not a bare boolean.

**Part A: Create lib/cli.sh**

2. **show_help()** — move from hardnormly.sh lines 55-81. Keep identical output. The function receives `$0` as an argument (or uses `${BASH_SOURCE[0]}` from the main script context — prefer passing script name as arg: `show_help "$0"`). Actually, since show_help just prints usage, it can use a hardcoded script name or receive it. Keep it simple: use `$0` directly since it's set by the shell for the main script.

   Important: `show_help` currently calls `exit 1`. Keep this behavior — it's a terminal function.

3. **show_version()** — extract the `--version` handling. Takes version string as argument. Prints and exits 0.

4. **parse_args()** — extract the entire while/case argument parsing loop (hardnormly.sh lines 102-238). This function receives `"$@"` from main and must set variables in the CALLER's scope.

   Implementation approach: Use **namerefs** (bash 4.3+) is complex for this many variables. Instead, use a simpler pattern: `parse_args` sets global variables directly (these are the CLI state variables that the orchestrator needs). This is acceptable because parse_args is only called once from the orchestrator, and these variables are consumed by the orchestrator to pass as arguments to module functions.

   The function must set these variables (declare them at the top of hardnormly.sh before calling parse_args):
   - `include_bed_files`, `exclude_bed_files`, `filters` (arrays)
   - `filters_file`, `fasta_file`, `vcf_file`, `output_vcf`, `genome_file`, `genome_build`, `log_file`, `plot_output_dir`, `tmp_dir` (strings)
   - `debug`, `cleanup`, `only_pass`, `generate_stats`, `plot_stats`, `auto_index` (booleans as strings)
   - `slop` (integer)
   - `version` (passed in, used by --version handler)

   Pattern: parse_args modifies the caller's variables. The caller declares them before calling parse_args. This is standard bash — functions modify variables in their enclosing scope unless `local` is used.

5. **validate_args()** — extract the validation logic (lines 240-256): plot_stats requires generate_stats + plot_output_dir, vcf_file and fasta_file required. Uses `log_msg` and `show_help` (available because logging.sh is sourced first).

6. **parse_filter_args()** — extract the inline + file-based filter parsing (lines 437-451) into a function that uses nameref:
   ```bash
   parse_filter_args() {
       local -n _stages_ref="$1"
       local filters_file="$2"
       shift 2
       local -a inline_filters=("$@")
       # ... parse inline and file-based filters into _stages_ref
   }
   ```
   This uses nameref so the caller controls the array lifecycle (important for testability per Research Pitfall 5 and 7).

Ensure shfmt and shellcheck compliance. For shellcheck: add `# shellcheck disable=SC2034` on any nameref line that shellcheck flags as "unused".
