**tests/05-lib-logging.bats — Unit tests for lib/logging.sh:**

Source only lib/logging.sh in setup(). These tests verify logging functions in isolation.

Test cases:

1. **log_msg writes to stdout when no log file set:**
   - Call `log_msg "test message"`
   - Assert output contains "test message" and a timestamp pattern

2. **log_msg writes to file when log file is set:**
   - Set log file via `set_log_file "${BATS_TEST_TMPDIR}/test.log"`
   - Call `log_msg "file message"`
   - Assert the file contains "file message"
   - Reset with `set_log_file ""` after test

3. **debug_msg outputs nothing when debug is false:**
   - Ensure `_DEBUG` is false (default)
   - `run debug_msg "hidden"` should produce no output

4. **debug_msg outputs when debug is true:**
   - `set_debug "true"`
   - `run debug_msg "visible"` should contain "[DEBUG] visible"
   - Reset with `set_debug "false"`

5. **error_msg writes to stderr:**
   - Capture stderr: `run error_msg "error text"`
   - Assert output contains "ERROR: error text"

6. **run_cmd succeeds for valid command:**
   - `set_tmp_dir "${BATS_TEST_TMPDIR}"`
   - `run run_cmd true` — assert success

7. **run_cmd fails with rich error for invalid command:**
   - `set_tmp_dir "${BATS_TEST_TMPDIR}"`
   - `run run_cmd false` — assert failure
   - Assert output contains exit code and command name

8. **run_cmd cleans up stderr temp file on success:**
   - Count files in BATS_TEST_TMPDIR before and after run_cmd
   - No runcmd-* files should remain after successful run

9. **run_cmd captures stderr on failure:**
   - Create a script that writes to stderr and exits 1
   - `run run_cmd bash -c 'echo "err output" >&2; exit 1'`
   - Assert output contains "err output"

**tests/06-lib-cli.bats — Unit tests for lib/cli.sh:**

Source lib/logging.sh then lib/cli.sh in setup() (cli.sh uses logging functions).

Test cases:

1. **show_help outputs usage text:**
   - `run show_help`
   - Assert failure (exit 1) and output contains "Usage:"

2. **show_version outputs version string:**
   - Set `version="test_ver"` before calling
   - `run show_version` — assert output contains "test_ver"

3. **parse_filter_args parses inline filters:**
   - Create a local `filter_stages` array
   - Call `parse_filter_args filter_stages "" "FilterA e QUAL<30"` (empty file, one inline)
   - Assert `filter_stages` contains "FilterA|e|QUAL<30"

4. **parse_filter_args parses filter file:**
   - Create a temp filter file with two lines
   - Call `parse_filter_args filter_stages "$filter_file"`
   - Assert `filter_stages` has 2 entries with correct name|action|expression

5. **parse_filter_args handles empty inputs:**
   - Call with no inline filters and no file
   - Assert `filter_stages` is empty

6. **parse_filter_args strips carriage returns from filter file:**
   - Create a filter file with `\r\n` line endings
   - Assert parsed expressions don't contain `\r`

Note on BATS + sourced modules: In each setup(), source the modules:
```bash
setup() {
    load 'test_helper/common'
    _common_setup
    source "${REPO_ROOT}/lib/logging.sh"
    # For cli tests: also source cli.sh
}
```

The include guards ensure double-sourcing doesn't happen even if setup() runs multiple times.

**tests/07-lib-modules.bats — Unit tests for the 6 pipeline modules:**

Source logging.sh first (required by all modules), then source each module as needed. Use `_require_tools` since these tests call bcftools/bedtools.

Group tests by module using comment headers.

**bed.sh tests:**

1. **normalize_bed adds annotation column and sorts:**
   - Create a 2-line BED file (unsorted)
   - Call `normalize_bed "$input" "INCLUDE" "$output"`
   - Assert output has 4 columns with "INCLUDE" in column 4
   - Assert output is sorted by position

2. **create_header_file writes correct VCF INFO header:**
   - Call `create_header_file "INCLUDE_REGION" "Included region" "$output"`
   - Assert file contains `##INFO=<ID=INCLUDE_REGION`

3. **compress_index_bed creates .gz and .tbi:**
   - Create a valid BED file, call `compress_index_bed "$bed"`
   - Assert `${bed}.gz` and `${bed}.gz.tbi` exist

**annotate.sh tests:**

4. **annotate_vcf_with_regions annotates VCF with BED regions:**
   - Use a small synthetic VCF and BED from test data
   - Call `annotate_vcf_with_regions` with include regions
   - Query output VCF for INCLUDE_REGION INFO field
   - Assert the field exists on variants within the BED region

**normalize.sh tests:**

5. **normalize_vcf produces valid output:**
   - Use synthetic VCF and mini_ref.fa
   - Call `normalize_vcf "$vcf" "$fasta" "$output" "$BATS_TEST_TMPDIR"`
   - Assert output exists and is valid VCF (bcftools view -h succeeds)

**filter.sh tests:**

6. **apply_filter_stages applies a single filter correctly:**
   - Initialize pipeline with a small VCF
   - Call `apply_filter_stages "$tmp_dir" "TestFilter|e|QUAL<30"`
   - Query filter_current.bcf for FILTER field
   - Assert low-QUAL variants are tagged "TestFilter"

7. **write_filtered_output writes compressed VCF:**
   - With filter_current.bcf in tmp_dir
   - Call `write_filtered_output "$tmp_dir" "$output.vcf.gz" "false" "false"`
   - Assert output is valid VCF

8. **write_filtered_output applies PASS filter when requested:**
   - With filter_current.bcf containing tagged variants
   - Call `write_filtered_output "$tmp_dir" "$output.vcf.gz" "true" "false"`
   - Assert output contains only PASS variants

**genome.sh tests:**

9. **create_genome_file function exists and is callable:**
   - Just verify the function is defined (don't call it — requires network)
   - `run type create_genome_file` — assert success
   - Note: We can't test UCSC MySQL in CI. The function's correctness is verified by the integration tests that use pre-created genome files.

**stats.sh tests:**

10. **generate_stats produces stats file:**
    - Run a small pipeline to get a filtered VCF
    - Call `generate_stats "$vcf" "$stats_output"`
    - Assert stats file exists and contains "SN" (summary numbers) section

Setup pattern for pipeline modules:
```bash
setup() {
    load 'test_helper/common'
    _common_setup
    _require_tools
    source "${REPO_ROOT}/lib/logging.sh"
    source "${REPO_ROOT}/lib/cli.sh"
    source "${REPO_ROOT}/lib/genome.sh"
    source "${REPO_ROOT}/lib/bed.sh"
    source "${REPO_ROOT}/lib/annotate.sh"
    source "${REPO_ROOT}/lib/normalize.sh"
    source "${REPO_ROOT}/lib/filter.sh"
    source "${REPO_ROOT}/lib/stats.sh"
    set_tmp_dir "${BATS_TEST_TMPDIR}"
}
```

Important: Each test must be independent — use BATS_TEST_TMPDIR for all temp files. Don't rely on state from other tests.

For tests that need a VCF in filter_current.bcf format, use `init_filter_pipeline` to set up the starting point from a synthetic VCF.
