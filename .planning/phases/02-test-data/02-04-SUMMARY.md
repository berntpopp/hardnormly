## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fixed exclude BED normalization: "exclude" annotation vs integer 1**

- **Found during:** Task 1 (Generate expected output VCFs)
- **Issue:** `normalize_bed` was called with annotation `"exclude"` for exclusion BEDs, but `EXCLUDE_REGION` INFO field is declared as `Type=Integer`. bcftools annotate failed with "Could not parse EXCLUDE_REGION at 22:20101 .. [exclude]"
- **Fix:** Changed `normalize_bed "$bed_file" "exclude" "$normalized_file"` to `normalize_bed "$bed_file" "1" "$normalized_file"` (line 298 of hardnormly.sh)
- **Files modified:** `hardnormly.sh`
- **Verification:** Pipeline ran successfully past the annotation step
- **Committed in:** `01974f4` (Task 1 commit)

**2. [Rule 1 - Bug] Fixed bcftools norm --write-index flag syntax**

- **Found during:** Task 1, immediately after fix #1
- **Issue:** `bcftools norm ... -W tbi ...` caused "Failed to open file 'tbi'" — bcftools 1.20 requires `--write-index=tbi` (with `=`), not `-W tbi` (space-separated)
- **Fix:** Changed `-W tbi` to `--write-index=tbi` in bcftools norm command (line 390)
- **Files modified:** `hardnormly.sh`
- **Verification:** bcftools norm step completed successfully, normalized VCF written
- **Committed in:** `01974f4` (Task 1 commit)

**3. [Rule 1 - Bug] Fixed bcftools view --write-index flag in output_args array**

- **Found during:** Task 1, same run
- **Issue:** `output_args+=("-W" "tbi")` caused identical "Failed to open file 'tbi'" error in final bcftools view step
- **Fix:** Changed to `output_args+=("--write-index=tbi")` (line 475)
- **Files modified:** `hardnormly.sh`
- **Verification:** Final VCF output written with auto-created .tbi index
- **Committed in:** `01974f4` (Task 1 commit)
