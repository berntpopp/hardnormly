3 multiallelic sites:
- Site 1 (10100): biallelic SNP with 2 ALT alleles (C and T)
- Site 2 (20200): insertion with 2 ALT alleles (GA and GAA -- 1bp and 2bp insertions)
- Site 3 (30300): insertion with 2 ALT alleles (TA and TAA)

After `bcftools norm -m-any`, each site splits into 2 biallelic records (6 records total). AD adjusts per split.

**IMPORTANT for multiallelic.vcf:** The REF bases at each position MUST match the actual nucleotide in mini_ref.fa at that position. Since mini_ref.fa uses a repeating `ACGTACGTNN` pattern:
- Position 10100: Check what base is there. With 10-char repeat, position 10100 mod 10 = 0, so it's the 10th char of the pattern = 'N'. That won't work for REF.

**CORRECTION:** The repeating pattern `ACGTACGTNN` means every 10th position repeats. Position 1 = A, 2 = C, 3 = G, 4 = T, 5 = A, 6 = C, 7 = G, 8 = T, 9 = N, 10 = N, 11 = A, etc.

To avoid N positions, use positions that map to A, C, G, or T. Use positions where pos mod 10 is in {1,2,3,4,5,6,7,8}:
- 10101 (mod 10 = 1, base = A): REF=A, ALT=C,T
- 20202 (mod 10 = 2, base = C): REF=C, ALT=CA,CAA  (insertions relative to C)
- 30303 (mod 10 = 3, base = G): REF=G, ALT=GA,GAA

Wait -- for insertions, bcftools norm needs the REF base to match. Actually, for multiallelic splitting, bcftools norm -m-any splits ALT alleles. It does NOT need to validate against reference for simple splitting. The reference is needed for LEFT-ALIGNMENT normalization, which is a separate step.

**Pragmatic decision:** Since bcftools norm with -m-any for splitting does not require reference match for the split operation itself, keep the positions simple. But if the executor runs `bcftools norm -f mini_ref.fa`, the REF must match. Use positions that avoid N bases in the repeating pattern.

  <action>
Create `tests/generate_test_data.sh` -- a bash script that downloads public data and produces all real data subsets. Then execute it to generate the real data files that will be committed.

**Script requirements:**
- Shebang: `#!/usr/bin/env bash`
- Use `set -euo pipefail` for safety
- Create a temp directory for intermediate downloads, clean up on exit
- Check for required tools at start: bcftools, samtools, tabix, wget
- Be idempotent: skip downloads if output files already exist (use `-s` file size check or `-f` existence check)
- Print progress messages to stderr
- Accept optional `--force` flag to re-download everything

**Script structure:**

```bash
#!/usr/bin/env bash
set -euo pipefail

# Configuration
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
DATA_DIR="${SCRIPT_DIR}/data"
REAL_DIR="${DATA_DIR}/real"
SYNTH_DIR="${DATA_DIR}/synthetic"
REGION="22:16000000-16100000"
FORCE=false

# Parse arguments
[[ "${1:-}" == "--force" ]] && FORCE=true

# Create directories
mkdir -p "${REAL_DIR}" "${SYNTH_DIR}"

# Temp directory with cleanup trap
TMPDIR=$(mktemp -d -t testdata-XXXXXXXXXX)
trap 'rm -rf "$TMPDIR"' EXIT

# Check dependencies
for tool in bcftools samtools tabix wget; do
    command -v "$tool" >/dev/null 2>&1 || { echo "ERROR: $tool not found" >&2; exit 1; }
done

echo "=== Generating test data ===" >&2

# --- GIAB NA12878 ---
echo "Downloading GIAB NA12878..." >&2
GIAB_BASE="https://ftp-trace.ncbi.nlm.nih.gov/ReferenceSamples/giab/release/NA12878_HG001/latest/GRCh37"

if [[ "$FORCE" == true ]] || [[ ! -f "${REAL_DIR}/giab_NA12878_chr22_16M.vcf.gz" ]]; then
    wget -q "${GIAB_BASE}/HG001_GRCh37_1_22_v4.2.1_benchmark.vcf.gz" \
        -O "${TMPDIR}/giab.vcf.gz"
    wget -q "${GIAB_BASE}/HG001_GRCh37_1_22_v4.2.1_benchmark.vcf.gz.tbi" \
        -O "${TMPDIR}/giab.vcf.gz.tbi"
    bcftools view -r "${REGION}" "${TMPDIR}/giab.vcf.gz" -Oz \
        -o "${REAL_DIR}/giab_NA12878_chr22_16M.vcf.gz"
    bcftools index -t "${REAL_DIR}/giab_NA12878_chr22_16M.vcf.gz"
    echo "  GIAB VCF subset created" >&2

    # GIAB high-confidence BED
    wget -q "${GIAB_BASE}/HG001_GRCh37_1_22_v4.2.1_benchmark.bed" \
        -O "${TMPDIR}/giab_benchmark.bed"
    awk '$1=="22" && $3>=16000000 && $2<=16100000' "${TMPDIR}/giab_benchmark.bed" \
        > "${REAL_DIR}/giab_NA12878_chr22_16M_highconf.bed"
    echo "  GIAB high-conf BED created" >&2
else
    echo "  GIAB data exists, skipping (use --force to re-download)" >&2
fi

# --- 1000 Genomes Phase 3 ---
echo "Downloading 1000 Genomes samples..." >&2
KG_URL="https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/release/20130502/ALL.chr22.phase3_shapeit2_mvncall_integrated_v5b.20130502.genotypes.vcf.gz"

for SAMPLE in NA12878 NA19240 HG00096; do
    OUTFILE="${REAL_DIR}/1kg_${SAMPLE}_chr22_16M.vcf.gz"
    if [[ "$FORCE" == true ]] || [[ ! -f "$OUTFILE" ]]; then
        echo "  Streaming ${SAMPLE} from 1000G..." >&2
        tabix -h "${KG_URL}" "${REGION}" \
            | bcftools view -s "${SAMPLE}" --min-ac 1 \
            -Oz -o "${OUTFILE}"
        bcftools index -t "${OUTFILE}"
        echo "  1kg_${SAMPLE} created" >&2
    else
        echo "  1kg_${SAMPLE} exists, skipping" >&2
    fi
done

# --- Freebayes tiny data ---
echo "Downloading Freebayes tiny data..." >&2
FB_RAW="https://raw.githubusercontent.com/freebayes/freebayes/master/test/tiny"

if [[ "$FORCE" == true ]] || [[ ! -f "${REAL_DIR}/freebayes_tiny.vcf.gz" ]]; then
    wget -q "${FB_RAW}/q.vcf.gz" -O "${REAL_DIR}/freebayes_tiny.vcf.gz"
    wget -q "${FB_RAW}/q.vcf.gz.tbi" -O "${REAL_DIR}/freebayes_tiny.vcf.gz.tbi"
    wget -q "${FB_RAW}/q.fa" -O "${REAL_DIR}/freebayes_tiny_ref.fa"
    wget -q "${FB_RAW}/q.fa.fai" -O "${REAL_DIR}/freebayes_tiny_ref.fa.fai"
    echo "  Freebayes tiny data downloaded" >&2
else
    echo "  Freebayes tiny exists, skipping" >&2
fi

# --- chr22 reference subset ---
echo "Creating chr22 reference subset..." >&2

if [[ "$FORCE" == true ]] || [[ ! -f "${REAL_DIR}/chr22_16M_ref.fa" ]]; then
    # Download hs37d5 reference (or use local if available)
    if [[ -f "ref/hs37d5.fa" ]]; then
        echo "  Using local ref/hs37d5.fa" >&2
        HS37D5="ref/hs37d5.fa"
    else
        echo "  Downloading hs37d5 reference (this will take a while)..." >&2
        HS37D5_URL="https://ftp.1000genomes.ebi.ac.uk/vol1/ftp/technical/reference/phase2_reference_assembly_sequence/hs37d5.fa.gz"
        wget -q "${HS37D5_URL}" -O "${TMPDIR}/hs37d5.fa.gz"
        gunzip "${TMPDIR}/hs37d5.fa.gz"
        samtools faidx "${TMPDIR}/hs37d5.fa"
        HS37D5="${TMPDIR}/hs37d5.fa"
    fi

    # Extract chr22 region and fix header
    samtools faidx "${HS37D5}" "22:16000000-16100000" \
        | sed '1s/.*/\>22/' > "${REAL_DIR}/chr22_16M_ref.fa"
    samtools faidx "${REAL_DIR}/chr22_16M_ref.fa"
    echo "  chr22 reference subset created" >&2
else
    echo "  chr22 reference exists, skipping" >&2
fi

echo "=== Test data generation complete ===" >&2

# Summary
echo "" >&2
echo "Files in ${REAL_DIR}:" >&2
ls -la "${REAL_DIR}/" >&2
```
