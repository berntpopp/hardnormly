# Phase 2: Test Data - Context

**Gathered:** 2026-02-18
**Status:** Ready for planning

<domain>
## Phase Boundary

Create all synthetic and real test data needed for automated tests. This includes synthetic VCFs triggering every GATK and Freebayes filter, utility VCFs for edge cases, real data subsets from public sources, a minimal test reference, expected output files, and a reproducible generation script. The test data enables Phase 3 (Test Framework) but does not include the tests themselves.

</domain>

<decisions>
## Implementation Decisions

### Real data sources
- GIAB NA12878 WES (exome) data — matches hardnormly's primary whole-exome use case
- 1000 Genomes: 3 samples from diverse superpopulations (EUR, AFR, EAS) for variant diversity
- All real data subsets scoped to a single ~100kb region for fast, small tests
- Freebayes tiny data sourced from Freebayes example/bundled data (not called from BAM)

### Synthetic VCF design
- Minimal variant count: 1 pass + 1 fail per filter trigger (smallest useful test set)
- Single-sample VCFs only (matches typical GATK HaplotypeCaller and Freebayes per-sample output)
- Utility VCFs: multiallelic (2-3 sites), empty_variants (header only), minimal (1 variant) — basics only
- No mixed-type or chr-naming variant VCFs needed for this phase

### Test region & reference
- Region: 22:16000000-16100000 (GRCh37, no 'chr' prefix — matches hs37d5 naming)
- Reference FASTA: extract 100kb subset from hs37d5.fa using samtools faidx, then re-index
- Subset FASTA works for bcftools norm as long as all test variants fall within the extracted region

### Expected output & regeneration
- `generate_test_data.sh` downloads real data from public URLs (NCBI/EBI/GitHub) — fully reproducible from scratch
- All generated files (synthetic + real subsets + expected outputs) committed to repo — tests work immediately after clone
- Expected output files generated by running current hardnormly.sh and capturing output (baseline = current behavior)
- Snakemake test configs: create config files and VCF lists only — actual Snakemake workflow testing deferred (needs cluster)

### Claude's Discretion
- How to split variants between GATK samples A and B (design for best test coverage)
- Exact public URLs for GIAB and 1000G downloads
- Directory structure within tests/data/
- Compression and indexing strategy for committed test files

</decisions>

</specifics>
