(For sample B, change `SAMPLE_A` to `SAMPLE_B` in the header line.)

**CRITICAL RULES:**
- All fields in INFO column must be semicolon-separated (e.g., `AS_FS=1.0;AS_SOR=0.5;AS_MQ=60.0`)
- FORMAT fields are colon-separated in both FORMAT and sample columns (e.g., `GT:DP:AD` and `0/1:20:10,10`)
- FORMAT/AD has Number=R, so biallelic sites have 2 values: ref,alt (e.g., `10,20`)
- FORMAT/DP must be >= sum(AD) -- set DP = sum(AD) for simplicity
- FORMAT/VAF is NOT in the header -- `bcftools +fill-tags` computes it from AD
- Use `.` for missing INFO fields, NOT empty string
- All data columns are TAB-separated
- POS must be sorted in ascending order within the file
- REF bases at each POS MUST match the actual nucleotide in mini_ref.fa at that 1-based position
- For SNPs, use single base REF->ALT where REF matches the reference. For INDELs, use REF=X ALT=XY (insertion) or REF=XY ALT=X (deletion), where X is the actual base at POS in the reference.
