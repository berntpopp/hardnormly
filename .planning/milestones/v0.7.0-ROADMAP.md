# Milestone v0.7.0: Code Quality, Testing & Features

**Status:** ✅ SHIPPED 2026-02-18
**Phases:** 1-5
**Total Plans:** 19

## Overview

Transform hardnormly from a 463-line monolithic bash script with no tests or CI into a
well-structured, tested, linted, and documented tool with new capabilities. The path ran
infrastructure first (linting, CI), then test data, then tests that make refactoring safe,
then modularization, then features that depend on the modular structure.

## Milestone Summary

**Key Decisions:**

- Focus on main script, not Snakemake workflow (Snakemake needs cluster testing separately)
- Replace real test data with synthetic + public data (no clinical data in repo; reproducible tests)
- BATS framework for testing (bash-native, well-supported, standard for bash projects)
- lib/ modularization with source-able functions, each module independently testable
- Array-based filter pipeline: `filter_stages` array with `|` delimiter (pipe cannot appear in bcftools filter expressions)
- Subcommand dispatcher: case on `_subcommand="${1:-}"`; `-*` falls through to legacy parse_args
- `.githooks/` over `.git/hooks/` — tracked in git, shareable via setup-hooks.sh
- shfmt flags: `-i 0 -bn -ci` (tabs, binary ops at line start, case indent)
- ERR trap removed; cleanup_handler is sole cleanup mechanism

**Issues Resolved:**

- Issue #13 (-g/--genome flag) — verified working by TFWK-06 tests, closed
- Hardcoded PATH in generate_expected.sh — documented as dev-only, deferred
- CRLF corruption on Windows — fixed with `.gitattributes eol=lf` for *.sh *.bash *.bats
- `make help` Windows failure — documented (sh.exe @echo issue), non-blocking

**Issues Deferred:**

- `tests/data/generate_expected.sh` has hardcoded PATH (dev-only script, non-blocking)
- Snakemake workflow refactoring — needs cluster testing on nserver separately

**Technical Debt Incurred:**

- None significant. The array-based filter pipeline and lib/ modularization addressed pre-existing eval fragility.
