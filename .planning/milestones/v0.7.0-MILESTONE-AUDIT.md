### Bug Found During Debt Resolution

Items 5 & 6 revealed a latent bug: `cmd_generate_inclusion_bed` and `cmd_generate_exclusion_bed` both used `[[ "$verbose" == true ]] && log_msg "..."` as their last statement. With `verbose=false`, `[[` returns exit code 1; bash's `set -e` exempts the `[[` inside the `&&` list but the function's **return value** was 1, triggering `set -e` in the caller before `exit 0` was reached. Fixed by adding explicit `return 0` at the end of each function.
